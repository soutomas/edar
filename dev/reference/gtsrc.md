# Convert a gtsummary object to flextable and add a source label

Convert a gtsummary object to flextable and add a source label

## Usage

``` r
gtsrc(gtsum, omit = "", span = 1)
```

## Arguments

- gtsum:

  A gtsummary object.

- omit:

  `<chr>` Text to omit from the label.

- span:

  `<num>` Number of lines of source label: either 1 or 2.

## Value

A flextable object with source label.

## Examples

library(gtsummary)
mtcars |> tbl_summary() |> gtsrc()
